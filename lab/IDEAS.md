# ATHENA NOCTUA — IDEAS REGISTER

The complete record of every structural idea the project has considered, and the research grounding each one.

HOW THIS FILE WORKS:
- Append-only for new ideas. A new major structural idea gets the next free F-number. Never reuse or renumber.
- Status can be edited in place (Alive / Settled / Dropped / Dead / Parked / Merged / Done / Promoted / Reassigned / Resurrected), but the row stays forever. A status is CONTEXTUAL, not a gravestone: it means "ruled out / parked under the assumptions named in its Cons cell", not "never". A new idea that changes those assumptions can RESURRECT a dead or parked idea. When reviving one, add a note and keep the history; never delete a row.
- LEAD = 1–10, how strongly this idea leads the next build under the current (Level-3, defined-silence, cover-synthesis) build.
- Refs column points to the numbered reference list at the bottom. "—" = no paper, it's a design/instinct idea.
- This is the ideas home. STATE.md holds current status, locked rules, plan and gates; it can point here rather than duplicate the table.

Last updated: 24 July 2026.

**24 Jul 2026 — Level-3 pivot (LOG H-007).** The build is now distribution-preserving cover-synthesis (the stego is a *sampled* noise floor whose coordinates encode the payload), not perturbation hiding (floor + delta). The security bar is Level 3: indistinguishable from a genuine floor to *any* distinguisher, provable via the coupling theorem, not "beats the one detector we trained". Net effect on this register: F3, F6, F20, F25 promoted to lead 10; F15 resurrected as load-bearing; F4, F22, F23 reassigned/demoted; F29–F38 appended; silence itself defined as F35. All status changes are in place per the contextual-status rule; no rows removed.

**24 Jul 2026 — cover fork closed (synthetic).** The named-distribution fork (F32/F35) is resolved on the DEFINED SYNTHETIC side: the cover is a specified mathematical noise floor, not a matched real recorder. The security claim is internal consistency against fresh draws of the declared distribution; there is no external recording to compare against. Colour/PSD is left declared-but-unset pending Phase 0 measurement of what reads cleanest.

**Companion project (forthcoming): *Silent Signal*.** Physical and acoustic silence (real recorded floor, and silence transmitted as an actual acoustic signal) is out of scope for Athena Noctua and deferred to a forthcoming companion project, working title *Silent Signal*. Ideas parked here "for the acoustic fork" (F7, F8, F9, F10) are the seeds that project inherits.

1. **WavInWav** — Fan, Chen, Wang, Zhang, Yu. *Time-domain Speech Hiding via Invertible Neural Network.* arXiv:2510.02915v1, 2025. Nearest INN-audio prior art; multi-resolution STFT loss, L_z Gaussian prior on residual, encryption add-on. The lineage F23 sits in.

4. **Steg-cINN** — Ren, Liu, Zhai, Wang. *Hiding Data in Colors: Secure and Lossless Deep Image Steganography via Conditional Invertible Neural Networks.* arXiv:2201.07444v1, 2022. Conditional INN; statistical-security framing behind F6/F24/F25.
5. **Deep Steganography** — Baluja. *Hiding Images in Plain Sight.* NeurIPS 2017. Encoder/decoder image-in-image; evading StegExpose/RS (F6).
6. **Fridrich & Goljan** — *Practical Steganalysis of Digital Images – State of the Art.* SPIE 2002. (i) bit-replacement/LSB is inherently detectable; (ii) steg mimicking small-amplitude sensor noise is fundamentally more secure. Grounding for F3 and the silent-cover pivot.

10. **Coupling-INN universality** — Teshima, Ishikawa, Tojo, Oono, Ikeda, Sugiyama. NeurIPS 2020. arXiv:2006.11469v2. Licence that a coupling INN is not less expressive than a CNF.
11. **Reversible Architectures** — Chang, Meng, Haber, Ruthotto, Begert, Holtham. AAAI 2018. Reversible-net memory/stability background.
12. **Scalable Normalizing Flows for Permutation Invariant Densities** — Biloš, Günnemann. ICML 2021. arXiv:2010.03242v2. [confirm authors from arXiv before citing]
13. **Point Process Flows** — arXiv:1910.08281v3. [authors NOT verified; weakest relevance — review whether it stays]
14. **Perfectly Secure Steganography via Minimum Entropy Coupling** — Schroeder de Witt, Sokota, Kolter, Foerster, Strohmeier. ICLR 2023. arXiv:2210.14889. THE theorem under this build: a procedure is perfectly secure (Cachin) iff it is induced by a coupling; throughput-optimal iff a minimum-entropy coupling. First perfect-security guarantees for arbitrary covertext distributions. Grounds F25/F29/F33 and the security bar. *(web-verified 24 Jul)*
15. **Meteor** — Kaptchuk, Jois, Green, Rubin. *Cryptographically Secure Steganography for Realistic Distributions.* ACM CCS 2021. Keyed-whitening (XOR message with a keyed PRNG mask) + entropy-adaptive sampling; provably indistinguishable from honest model output even when the observer knows the model. The applied predecessor; grounds F15/F29/F33. *(web-verified 24 Jul)*
16. **Neural Linguistic Steganography** — Ziegler, Deng, Rush. EMNLP-IJCNLP 2019. arXiv:1909.01496. Arithmetic-coding steganography over a neural LM; cites Sallee (ref 22) that AC yields q = p_s (D_KL → 0 for long sequences), so security = small D_KL and capacity = H(q). The direct textual analogue of F29/F33. *(PDF-verified 24 Jul)*
17. **DPL-COT** — Woźniak, Ogiela, Ogiela. *Distribution-Preserving Latent Image Steganography via Conditional Optimal Transport and Theoretical Target Synthesis.* Electronics 2026, 15, 1321. Coverless latent-image steg into an LDM's N(0,I) init noise: inverse-CDF truncated-Gaussian target synthesis + keyed whitening for bit balance + 1-D OT rank-preserving assignment; KS2 < 0.003, W1 < 0.003; names the LRT-on-latent-norm as the principled detector. Closest prior art to F29 in the image domain; grounds F3/F15/F32/F33/F34. *(PDF-verified 24 Jul)*
18. **Physics-Aware Shannon-Optimal Compression via Arithmetic Coding** — Fanelli. 2026. Integer-CDF arithmetic coding is exactly invertible (encode→decode→bitwise closure) and Shannon-optimal; average codelength = H(p) + D_KL(p‖q), so excess codelength MEASURES distributional mismatch in bits; session-split to avoid leakage; explicit conditional factorisation of a discrete, sparse, heavy-tailed integer readout. Grounds F30/F31/F34 and the detector-as-instrument reframe. *(PDF-verified 24 Jul)*
19. **WaveNet** — van den Oord et al. arXiv:1609.03499, 2016. Neural per-sample audio distributions conditioned on context; the entropy-model principle behind F29. *(standard; not re-verified against source this session)*
